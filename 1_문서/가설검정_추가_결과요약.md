# 추가 가설검정 결과: 임금 → 이직률(H7), 성과급 → 생산성(H8)

2026-11-22 · 사전 계획: `../가설검정_추가_사전계획.md` (결과 보기 전 경계값·주 검정 고정) · 코드: `h7_h8_분석.py` · 표: `결과/`
데이터: WPS 2015~2023(5개 회차, 민간 회사법인, 금융·공공 제외, 정규직 10명 이상, 10,939행·2,901곳). 보조: DART 평균근속연수. WPS 원자료는 공유하지 않고 집계표만 저장.

## 한 줄 결론
- **임금 → 이직률: 관계 있음.** 같은 업종·연도에서 임금이 10% 높은 회사는 정규직 자발적 이직률이 약 0.45%p 낮다. 임금 위치 하위 20% 회사의 자발적 이직률은 상위 20%보다 약 5%p 높다(17.8% vs 12.7%).
- **성과급 → 생산성: 근거 없음.** 성과급을 준 회사의 이후 생산성이 높아 보이는 것은 **성과급이 성과를 뒤따르기 때문**이다(지급 전 2년 동안 이미 생산성이 12% 더 늘어 있었다). 성과급을 새로 도입한 회사만 보면 이후 생산성 변화는 유의하지 않다.

## H7. 임금이 높은 회사는 자발적 이직률이 낮다

| 모형 | 임금 10%당 이직률 변화 | 95% 구간 | p |
|---|---|---|---|
| **★주 검정: 횡단** (통제 + 중분류×연도) | **−0.45%p** | −0.58 ~ −0.33 | < 0.001 (Holm < 0.001) |
| 성과배분 동시 투입 | −0.44%p | −0.57 ~ −0.32 | < 0.001 |
| 근속 20년 이상·여성 비중 통제 (호봉 역방향 점검) | −0.37%p | −0.49 ~ −0.24 | < 0.001 |
| 시차: 2년 뒤 이직률 (현재 이직률 통제) | −0.44%p | −0.56 ~ −0.31 | < 0.001 |
| 단독사업장 / 제조원가 급여 결측 없음 / 1% 절단 | −0.35 / −0.54 / −0.47%p | | 모두 < 0.001 |
| 정규직 전체 이직률(자발 + 비자발) | −0.46%p | | < 0.001 |
| 임금 위치(동종 중앙 대비) 10%p당 | −0.43%p | | < 0.001 |
| **기업 고정효과** (같은 회사가 임금을 올렸을 때) | **+0.10%p** | −0.06 ~ +0.27 | 0.22 |

**임금 위치 5분위별 자발적 이직률** (업종·연도 조정)

| 분위 | 임금 위치 중앙 | 이직률 |
|---|---|---|
| 1 (가장 낮음) | −45% | 17.8% |
| 2 | −15% | 17.1% |
| 3 | 0% | 15.0% |
| 4 | +15% | 14.1% |
| 5 (가장 높음) | +40% | 12.7% |

- **크기:** 사전에 정한 "의미 있는 크기"는 ±0.5%p였고, 추정치(−0.45%p, 90% 구간 −0.56 ~ −0.35)가 그 근처에 있다. "효과가 있다"는 분명하지만 "크다"고 말하기는 어렵다. 평균 이직률(16.1%) 기준 탄력성 약 −0.3이다.
- **기업 고정효과에서는 사라진다.** 임금이 높은 회사가 이직이 적은 것은 분명하지만, 한 회사가 2년 사이 임금을 올린 만큼 이직이 줄어드는지는 이 데이터로 확인되지 않는다. 가능한 이유: ① 2년 사이 임금 변화는 작고 측정 오차가 커서 효과가 희석된다. ② 임금 수준 자체보다, 임금이 높은 회사의 다른 특성(안정성·평판)이 이직을 줄인다.
- **DART 보조:** 임금 10%당 평균근속연수 +5.6%(횡단), +3.0%(기업 FE), 모두 p < 0.001. 다만 호봉제에서는 근속이 길면 평균임금이 올라가는 역방향이 섞이므로 약한 보조 근거로만 쓴다.

## H8. 성과배분을 실시한 회사는 이후 생산성이 오른다

| 모형 | 효과 (1인당 부가가치, %) | 95% 구간 | p |
|---|---|---|---|
| **★주 검정: 시차** (성과배분_t → 변화 t → t+2) | **+5.3%** | +2.2 ~ +8.5 | 0.001 (Holm 0.001) |
| 임금 동시 투입 / 단독사업장 / 1% 절단 | +4.6 / +6.4 / +4.1% | | 모두 < 0.01 |
| 성과배분 수준 1개월분당 | +4.5% | | < 0.001 |
| 1인당 매출 변화 | +2.1% | −0.3 ~ +4.5 | 0.09 |
| 영업이익률 변화 | +0.71%p | | 0.02 |

**주 검정만 보면 "성과급이 생산성을 올린다"처럼 보이지만, 점검하면 무너진다.**

| 점검 | 결과 | 의미 |
|---|---|---|
| **사전 추세** (지급 전 2년, t−2 → t) | **+12.2%** (p < 0.001) | 성과급을 준 회사는 주기 전에 이미 생산성이 더 늘었다 → 성과급은 성과에 대한 **보상** |
| 신규 도입 회사의 사전 추세 | +14.7% (p < 0.001) | 새로 도입한 회사도 직전에 성과가 좋았다 |
| **신규 도입 회사의 이후 변화** (t → t+2) | **+1.6%** (−3.3 ~ +6.5, p = 0.51) | 도입 후 생산성 상승은 확인되지 않는다 |
| 2년 뒤 실시 여부 통제 | −2.8% (p = 0.17) | 주 검정의 +5.3%는 "2년 뒤에도 성과가 좋아 또 준 회사"가 만든 것 |
| 분해: 부가가치 변화 중 인건비 부분 / 나머지 | +1.3% / +5.0% | 기계적 인건비 증가는 일부만 설명한다 |

- **판정:** 사전 계획의 주 검정은 유의하게 양(+)이다. 하지만 사전 추세 점검을 통과하지 못하므로 **"성과급이 생산성을 올린다"는 인과 해석은 지지되지 않는다.** 가장 깨끗한 비교(신규 도입)의 95% 구간(−3.3 ~ +6.5%)은 0과 성과배분 비용(약 2.8%)을 모두 포함한다. 그래서 "효과가 없다"고 단정할 수도 없다. 정직한 결론은 **"성과급이 생산성을 올린다는 근거는 이 데이터에 없다"**이다.
- H6-①(이익이 늘면 급여도 는다)과 같은 그림이다. **성과급은 생산성의 원인이라기보다 성과를 나누는 결과다.**

## 교차 (탐색)
- 성과배분 → 이직률: 횡단 −1.3%p(p = 0.01), 임금 통제 시 −1.2%p(p = 0.02), 기업 FE +0.5%p(p = 0.45). 성과배분을 하는 회사는 이직이 조금 적지만 같은 회사 안에서는 확인되지 않는다.
- 임금 → 이후 생산성: 임금 10%당 2년 뒤 1인당 부가가치 +2.0%(p < 0.001). 다만 부가가치에 인건비가 들어 있고 사전 추세 점검을 하지 않았으므로 해석하지 않는다.

## 에이전트와 문제 정의에 주는 의미
1. **임금의 근거는 "생산성"이 아니라 "인력 유지"다.** 동종업계 대비 임금 위치가 낮을수록 자발적 이직이 많다(하위 20%와 상위 20%의 차이 약 5%p). 진단 기능의 임금 위치 축은 이 관계를 근거로 둘 수 있다. "하위 20%면 이직률이 상위 20%보다 약 5%p 높은 집단에 속한다"는 식이다. 선배가 말한 "업계가 N% 올리면 우리도 비슷하게"라는 현업 관행과도 맞는다.
2. **성과급의 근거는 "생산성 향상"이 아니라 "성과 공유"다.** 성과급을 올려 생산성을 끌어올린다는 논리는 데이터로 뒷받침되지 않는다. 경영진 관점의 메시지는 이렇다: 성과급은 이익이 난 만큼 나누는 비용이다. 그래서 고정급보다 이익연동(기능 3)이 회사 위험을 줄이는 방식이다.
3. **한계:** 관찰 자료라 인과 효과를 증명하지 않는다. WPS는 2년 간격이고 성과배분 금액 문항(CQ3007)은 지급자 일부만 응답했다. 임금은 급여총액 ÷ 근로자 수라서 직급 구성 차이를 다 지우지 못한다.
