# 추가 가설검정 사전 계획 (결과 보기 전 고정, 2026-11-22)

선배 피드백("임금→이직률, 성과급→생산성을 별개의 독립변수로 나눠 확인")에 따른 추가 검정. 이 문서는 분석을 돌리기 전에 작성했고, 결과를 본 뒤 경계값·주 검정을 바꾸지 않는다.

## 데이터
- **주: WPS 2015·2017·2019·2021·2023.** 민간 회사법인(AQ2001=2), 금융(K)·공공(O) 제외, 연말 정규직(EPQ4008) 10명 이상, 재무 평균 근로자(FPQ1011) 10명 이상.
- **보조: DART 2015~2025.** 평균근속연수(공시 직원현황)로 임금→이직 방향을 재확인.

## 변수
| 변수 | 정의 |
|---|---|
| 자발적 이직률(%) | EPQ8041(정규직 자발적 이직) ÷ EPQ4008(연말 정규직) × 100, 150% 초과 제외 |
| ln 실질 1인당 급여 | (FPQ2006 + FPQ3001[결측 0]) ÷ FPQ1011, CPI로 2023년 가격. 최저임금 연액의 0.8배 미만·3억 원 초과 제외 |
| 임금 위치(%) | ln 1인당 급여 − 같은 대분류×규모×연도 중앙값(5곳 미만이면 대분류×연도) |
| 성과배분 실시 | CQ3001=1이고 CQ3002=1 → 1, CQ3001=2 또는 CQ3002=2 → 0 |
| 성과배분 수준(개월) | CQ3007 ÷ 100(월 통상임금의 몇 배), 미실시 0, 9,000,000 이상 코드·12개월 초과 제외 |
| ln 실질 1인당 부가가치 | (FPQ2015 + 급여·퇴직급여·복리후생비·임차료·세금과공과·감가상각비[판관비 + 제조원가, 원가 항목 결측 0]) ÷ FPQ1011, 0 이하 제외 |
| 통제 | ln 근로자 수, 정규직 비중(EPQ4008 ÷ EPQ3008), 노조 유무(EPQ7001 > 0), 중분류×연도 고정효과 |

## 가설과 주 검정
| | 가설 | 주 모형 | 효과 단위 | 동등성 경계 |
|---|---|---|---|---|
| **H7** | 임금이 높은 회사는 자발적 이직률이 낮다 | 횡단: 이직률 ~ ln 급여 + 통제 + 중분류×연도 FE, 사업체 클러스터 | 임금 10%당 %p | **±0.5%p** (이직의 임금 탄력성 −0.5 × 중앙 이직률 9.4%) |
| **H8** | 성과배분을 실시한 회사는 이후 생산성이 오른다 | 시차: Δln 1인당 부가가치(t → t+2, %) ~ 성과배분 실시_t + ln 1인당 부가가치_t + 통제 + 중분류×연도 FE | % | **±1.4%** (성과배분 비용 = 1인당 부가가치의 약 2.8%의 절반) |

- 두 주 검정은 Holm 보정. TOST는 90% 신뢰구간이 경계 안에 있는지로 판정.
- H7을 횡단으로 하는 이유: 임금 효과는 수준의 효과라서 현재 이직률을 통제하는 시차 모형에서는 지워진다. H8을 시차로 하는 이유: 성과배분은 이익이 나서 주는 것이라 같은 해 비교는 역방향 인과가 지배한다.

## 보조 (탐색, 보정 없음)
- 모형 3종을 모든 조합에: 횡단 / 기업 고정효과 / 시차
- 교차: H7b 성과배분 → 이직률, H8b 임금 → 생산성
- 단독 투입과 두 독립변수 동시 투입
- H7 대체: 임금 위치(10%p당), 임금 위치 5분위별 이직률, 정규직 전체 이직률(EPQ8031)
- H8 대체: 성과배분 수준(개월), Δln 1인당 매출, Δ영업이익률
- 견고성: 단독사업장, 제조원가 급여 결측 없는 행, 상하 1% 절단
- DART: ln 평균근속연수 ~ ln 1인당 급여 (횡단·기업 FE)

## 한계 (미리 명시)
관찰 자료라 인과 효과를 증명하지 않는다. WPS는 2년 간격. 재무는 기업 전체 기준인 사업장이 있다(단독사업장으로 확인). WPS 원자료는 공유하지 않고 집계 결과만 저장한다.
