# 🗂️ DART 수집·재파싱 코드

OpenDART에서 재무·직원 자료를 받아 `0_데이터/DART_패널`의 기업×연도 패널을 만든 코드임, 중단 후 다시 실행해도 이어서 진행함

## 🔑 준비

1. Python 3.9 이상, `pip install pandas`
2. [OpenDART](https://opendart.fss.or.kr) 키 발급, 키는 커밋하지 않음
3. `.env.example`을 `.env`로 복사해 키를 넣거나 환경변수 `DART_API_KEY` 설정
4. 기업 목록 CSV (`기업고유코드` 열이 있으면 됨)
5. `python 스크립트.py`로 실행 (`python -I`는 같은 폴더의 `dart_api.py`를 찾지 못함)

> 하루 호출 한도는 키당 약 20,000건, 한도에 닿으면 멈추고 다음 날 같은 명령으로 이어받음

## 📜 스크립트

| 순서 | 파일 | 하는 일 | 호출량 |
| --- | --- | --- | --- |
| 1 | `01_collect_employees.py` | 직원현황 API 수집 | 기업·연도당 1건 |
| 2 | `02_download_filings.py` | 사업보고서 원문 ZIP 내려받기 | 기업당 2~3건 |
| 3 | `03_parse_filings.py` | 원문에서 감가상각비·인건비·세금과공과·대손상각비 추출 | 없음 |
| 4 | `04_fix_employees.py` | 직원현황 합계 행 이중 집계 교정 | 없음 |
| 5 | `05_collect_main_accounts.py` | 주요계정 API로 별도 영업이익·매출·자산 수집 | 연도당 약 34건 |
| 6 | `06_collect_company_info.py` | 기업개황 API로 업종코드·상장시장 수집 | 기업당 1건 |
| 7 | `07_collect_interest.py` | 전체 재무제표 API로 이자비용 수집 | 기업·연도당 1건 |
| 8 | `08_extract_tenure.py` | 근속연수 추출 | 없음 |
| - | `run_year.py` | 위 단계를 연도별로 순서대로 실행 (`--plan`으로 호출량만 계산) | 단계별 합계 |
| - | `build_panel.py` | 수집 결과를 기업×연도 패널 한 파일로 합침 | 없음 |

## 🚀 실행 예

```bash
python run_year.py --corps 기업목록.csv --years 2024 --out 결과폴더 --plan   # 호출량 계산
python run_year.py --corps 기업목록.csv --years 2024 --out 결과폴더          # 05 → 01 → 04 → 02 → 03
python run_year.py --corps 기업목록.csv --years 2024 --out 결과폴더 --steps 07
```

`build_panel.py`는 환경변수 `HR_DATA_DIR`(기본: 홈 폴더의 Downloads) 아래의 중간 산출물을 읽음, 주석 항목 일부는 팀 내부 작업 폴더의 결과가 필요해 이 저장소만으로는 패널을 처음부터 다시 만들 수 없음, 완성된 패널은 `0_데이터`에 있음

## ⚠️ 수집하며 확인한 문제

| 문제 | 처리 |
| --- | --- |
| 직원현황의 "성별합계·소계" 행을 부문 행과 함께 더하면 직원 수가 2배가 됨 | `04`가 합계 행만 사용 |
| 원문 ZIP 하나에 사업보고서·별도 감사보고서·연결 감사보고서가 함께 있음 | `03`이 별도 문서를 우선하고 연결 감사보고서는 쓰지 않음 |
| 정정 공시가 여러 건 | `02`가 가장 늦은 접수본부터 받아 재무제표가 있는 문서를 고름 |
| 특수관계자 주석의 경영진 보상 표가 비용 표로 섞임 | 재고자산·원재료 행과 급여 행이 함께 있는 표만 성격별 비용 표로 판별 |
| 금융비용에는 외환차손·파생손익이 섞여 이자비용과 다름 | 손익계산서 이자비용, 없으면 현금흐름표 이자지급 사용 |
| 표에 행이 없는 것과 값이 0인 것이 다름 | `T_found`·`B_found`·`tb_status`로 구분 |
