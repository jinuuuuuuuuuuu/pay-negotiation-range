## 🎯 프로젝트 개요

노조가 성과급·임금 인상을 요구하면 회사는 "몇 %가 적정한가"를 정해야 하지만, 현업에서는 주로 "동종업계가 N% 올렸으니 우리도 그 근처"로 판단함

- 합의는 교섭력으로 정해지기 때문에 **정답 한 점을 줄 수는 없음**
- 여력이 있어도 경영진은 배당·재투자를 먼저 고려하므로, **"여력이 있으니 더 준다"는 가정은 맞지 않음**
- 근로자 입장만 대변하는 도구는 경영진에게 쓸모가 없음

그래서 본 프로젝트는 **노사 양쪽이 각자 내세울 수 있는 근거를 숫자로 보여 주는 협상 구간**을 만듦

```text
        하한 ├──────── 협상 구간 ────────┤ 상한
   "이 아래면 업계에 뒤처짐"          "이 위면 업계보다 부담이 큼"
      (노측이 내세울 근거)              (사측이 내세울 근거)
```

| 설계 원칙 | 구현 방식 |
| --- | --- |
| 🏢 비슷한 회사와 비교 | 같은 업종에서 매출·1인당 자산이 비슷한 20개 회사를 비교군으로 자동 선정 |
| ⚖️ 양쪽 근거를 함께 | 하한은 업계 인상률, 상한은 업계와 같은 부담 수준 |
| 🧮 계산은 한 곳에서 | 모든 산술식은 `formula.py` 하나에 두고, 앱 계산과 일치하는지 자동 검사 |
| 🚧 근거의 한계도 표시 | 인과가 확인되지 않은 결과와 참고용 예측을 화면에서 구분 |

### 💬 한 줄 정의

> **정답 한 점이 아니라, 양측이 각자 내세울 수 있는 근거의 범위를 보여 주는 도구임**

## 🧮 협상 구간 계산

### 하한 = 업계 인상률

비교군 20곳의 최근 3년 1인당 급여 연 증가율 중앙값임, 이보다 낮으면 업계에 뒤처짐

### 상한 = 업계와 같은 부담 수준

```text
상한 = 업계 인상률 × (우리 이익÷급여) ÷ (비교군 이익÷급여 중앙값)
```

인상 비용이 영업이익에서 차지하는 비중을 비교군과 똑같이 맞췄을 때의 인상률임, 상한은 "감당할 수 있는 한도"가 아니라 **업계 기준으로 맞춘 선**임

| 예시 (가상 숫자) | 우리 이익÷급여 | 상한 |
| --- | ---: | ---: |
| 업계 인상률 5%, 비교군 이익÷급여 0.5 | 1.0 | 10% |
| 〃 | 0.25 | 2.5% |

> 상한이 하한보다 낮은 회사는 "구간 없음"이 아니라 **업계만큼 주면 우리 부담이 업계보다 크다**는 신호로 보고, 고정 인상 대신 이익연동 전환(기능 3)을 검토하도록 안내함

### 상한 정의를 정하기까지

"감당 가능한 한도"를 회사 한 곳의 숫자로 정하려고 네 가지 규칙을 시험했지만 모두 안정적이지 않음

| 시험한 규칙 | 결과 |
| --- | --- |
| 영업이익률의 평소 출렁임만큼 | 상한 중앙값 45%로 사실상 상한이 아님 |
| 비용 ≤ 영업이익의 10% | 61% 회사에서 상한이 하한보다 낮음 |
| 1인당 부가가치 증가율만큼 | 회사마다 ±20%로 널뛰고 65%가 상한 < 하한 |
| 비교군의 이익 대비 부담 (중앙값) | 70%가 상한 < 하한 |

## 📊 분석 결과

| 가설 | 결과 | 데이터 |
| --- | --- | --- |
| H7 임금 → 이직 | 임금이 10% 높은 회사는 자발적 이직률이 **0.45%p 낮음**. 업계 대비 임금 하위 20%의 이직률 17.8%, 상위 20%는 12.7%. 단, 같은 회사가 임금을 올렸을 때 이직이 줄어드는지는 확인되지 않음 | WPS 사업체패널 2015~2023 |
| H8 성과급 → 생산성 | 성과급이 생산성을 올린다는 근거를 찾지 못함, 성과급을 준 회사는 지급 전에 이미 생산성이 늘어 있었음 (성과급은 성과를 뒤따름) | WPS 사업체패널 2015~2023 |
| 다음 해 적자 예측 | 적자 해를 가려내는 정확도가 높지 않아 (AUC 0.66) 참고 지표로만 사용 | DART 2023~2025 |
