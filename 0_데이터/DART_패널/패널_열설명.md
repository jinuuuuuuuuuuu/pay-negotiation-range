# DART 패널 열 설명 (DART_패널_2015_2025.csv)

한 행 = 기업 × 사업연도. 단위는 원(직원수는 명). **결측은 0으로 채우지 않았고, 행은 지우지 않았습니다.**
확정 전 자료이며 주석 항목(감가·세금·대손·W)은 모두 "후보"입니다(팀 v5.6 문구 그대로).

| 열 | 설명 | 출처 (변수당 하나) |
|---|---|---|
| 기업고유코드, 사업연도, 기업명, 종목코드 | 키 | 기본 파일(24번) |
| 상장시장, 업종코드, 업종코드_중분류 | 업종은 현재 기준 하나(연도별 이력 없음). 중분류=앞 2자리. 비어 있으면 기업개황 API로 보충 | 24번 → 기업개황 |
| WPS기준연도 | 이 행에 붙일 WPS 조사연도(해당 연도, 없으면 직전 조사). 2015→2015, 2016→2015, 2017·18→2017, 2019·20→2019, 2021·22→2021, 2023~25→2023 | 규칙 |
| 공시접수번호, 공시접수검토 | 사용한 공시. 검토=1이면 접수 시점이 회계연도와 크게 어긋남 | 24번 |
| 직원수, 급여총액(원), 직원현황_상태 | 사업보고서 직원현황(임원 제외). 사업부문 합계 행이 있으면 그 행만 사용해 이중 집계 교정. 상태 `교정:합계행/교정:전체합`, `미교정(24번값)`=원자료 없음 | 직원현황 API |
| 영업이익(원), 매출액(원), 자산총계(원) | 별도(OFS) 기준 | 다중회사 주요계정 API |
| 이자비용(원), 이자비용_출처 | 손익계산서 이자비용 → 현금흐름표 조정 이자비용 → 현금흐름표 이자지급 순. 금융비용은 쓰지 않음 | 전체 재무제표 API |
| 감가상각비(원), 세금과공과(원), 대손상각비(원) + 각 _상태 | 주석 원문 후보값(별도·성격별 표 중심, 부분·범위 미확정 포함). 상태는 원문검증 필요 정도. 값이 비면 '미확보'(해당 행을 못 찾음 ≠ 0) | 팀 v5.6 20번 |
| 인건비총액W(원), 인건비W_상태 | 급여+퇴직급여+복리후생비 후보. 상태에 구성(3항목확인/종업원급여합계)과 `·급여총액대비이상`(W÷급여총액이 0.8~2.0 밖) 표시 | 팀 v5.6 20번 |
| 플래그_지주회사 | 업종 64992 또는 이름에 지주·홀딩스 | 규칙 |
| 플래그_급여이상 | 1인당 급여가 2천만 원 미만 또는 3억 원 초과(입력 오류 포함) | 규칙 |
| 플래그_직원10명미만 | 직원수 10명 미만 | 규칙 |
| 플래그_감가이상 | 감가상각비가 매출보다 크거나 음수(단위 오독 의심) | 규칙 |
| 플래그_이자이상 | 이자비용이 자산총계의 50% 초과 | 규칙 |

## 알려진 한계
- 2018·2019년 주석 항목은 팀원이 제공한 v5.6 재처리 결과, 그 외 연도는 같은 코드로 재처리한 결과. 2018년 직원수·이자비용은 팀원 원자료(API JSON)에 다른 연도와 같은 규칙을 적용(팀원 산출과 2,761곳 전부 일치 확인).
- 영업이익·매출·자산은 별도 공시가 없는 기업(연결만 공시 등)은 빈칸.
- 직원수에 DART 공시 자체의 입력 오류가 있음(예: 직원수 칸에 금액이 입력). 플래그_급여이상으로 확인.
- 비교군, WPS 결합, 산술식 결과는 이 파일에 포함하지 않음.
