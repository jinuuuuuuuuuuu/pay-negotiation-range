# 📎 DART 보조 자료

DART 패널에 없는 두 항목을 공시에서 뽑은 파일임, 산술식 실행(`run_산술식.py`)에서 패널과 함께 읽음

| 파일 | 열 | 내용 |
| --- | --- | --- |
| `영업현금흐름_2015_2025.csv` | `id`, `yr`, `CFO` | 기업고유코드, 사업연도, 영업활동현금흐름(별도, 원) |
| `공시평균급여_근속_2015_2025.csv` | `id`, `yr`, `avg_disc`, `ten` | 기업고유코드, 사업연도, 직원현황에 공시된 1인 평균급여(원), 평균 근속연수(년) |

> 값은 공시 원문 그대로이며 단위 오기가 섞여 있을 수 있음, 산술식은 급여총액÷직원수와 크게 어긋나는 기업에 「급여 확인」 표시를 함
